StreamONER とは

StreamONER は、配信者向けのデスクトップアプリケーションです。 OBS で使う配信オーバーレイの表示と操作を助けることが目的です。

対応環境: Windows / macOS（配布インストーラは主に Windows x64）。

できること

  • Discord のボイスチャンネル参加者表示と発話ハイライトを、OBS のブラウザソースに表示する
  • YouTube ライブチャットを、配信中に OBS のブラウザソースへ表示する
  • マイク入力に連動するアバター（口パク）オーバーレイを表示する
  • これらのオーバーレイを配信制作のワークフローに合わせてまとめて使う

CSS エディタ

YouTube チャット / Discord VC の見た目（フォント・色・バッジ・発話ハイライトなど）をブラウザで調整し、カスタム CSS としてダウンロードできます。

CSS エディタを開く · https://streamoner.mutti.xyz/css-editor/

Google / YouTube アカウント連携が必要な理由

StreamONER は、ユーザーが許可した場合に限り、Google の認可を使って 認可したユーザー自身の YouTube データへ読み取り専用でアクセスします。 利用スコープは https://www.googleapis.com/auth/youtube.readonly のみです。

この権限は、次の目的にだけ使います。

  1. 認可したユーザーの YouTube チャンネルを確認し、連携状態を表示する
  2. そのユーザーが配信中の YouTube ライブを検出し、対象の動画 ID を取得する

ライブチャット表示は別のユーザー向け機能であり、 Google OAuth のアクセストークンおよびリフレッシュトークンを チャットメッセージの取得には使用しません。

StreamONER は Google のパスワードを取得しません。 認証は Google の同意画面上で行われます。
