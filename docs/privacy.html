本プライバシーポリシーは、StreamONER（以下「本アプリ」）が取り扱う情報の種類、利用目的、保管・削除、および第三者への提供について説明します。

1. 収集・アクセスする情報

1.1 Google / YouTube 連携（OAuth）

ユーザーが Google アカウント連携を許可した場合、本アプリは、認可したユーザー自身の次の YouTube データにアクセスします。

内容 目的
チャンネル ID・チャンネル名 認可したチャンネルの確認と連携状態の表示のため
YouTube アカウントに紐づく配信（ライブ）情報 配信中のライブを検出し、対象の動画 ID を取得するため

利用する権限（スコープ）は次のとおりです。

  • https://www.googleapis.com/auth/youtube.readonly（YouTube データの表示・読み取り）

本アプリは、ユーザーの Google パスワードを取得・保存しません。認証は Google の画面上で行われます。

Google OAuth のアクセストークンおよびリフレッシュトークンは、チャンネルの確認、配信中のライブ検出、および連携状態の維持にのみ使用し、ライブチャットメッセージの取得には使用しません。

1.2 ライブチャット表示で扱う情報

本アプリのライブチャット表示機能では、視聴者（第三者）の表示名・コメント・スーパーチャット等の表示用情報を扱う場合があります。これらは、配信者であるユーザーが本アプリおよび OBS 上でコメントを表示するために、ユーザーの端末上で処理・表示されます。

このライブチャット表示機能は Google OAuth によるアカウント連携とは別の機能であり、チャットメッセージの取得に Google OAuth のトークンは使用しません。

1.3 端末に保存する情報

本アプリは、主にユーザーの端末上に次の情報を保存します。

  • OAuth のアクセストークンおよびリフレッシュトークン（連携維持用）
  • アプリ設定（表示レイアウト、マイク設定、テーマ等）
  • ユーザーが任意で入力した API キーや Discord 用シークレット等

トークンやシークレット類は、OS が提供する暗号化ストレージに保存します。

1.4 データの送信先

  • Google / YouTube 連携時、本アプリはチャンネルの確認と配信中のライブ検出のため、ユーザーの端末から Google のサーバー（OAuth および YouTube Data API）へ必要なリクエストを送信します。
  • 取得した YouTube 関連データおよび OAuth トークンを、運営者の独自サーバーへ送信・アップロードする仕組みはありません（本ポリシー最終更新時点）。
  • チャット表示のため、ユーザーが設定した OBS 等のローカル環境、またはユーザーが有効にした同一 LAN 上のリモート操作画面へ、表示用データを送る場合があります。対象はユーザーの PC および同一 LAN 内に限ります。

2. 利用目的

取得した情報は、次の目的にのみ使用します。

  1. 認可した YouTube チャンネルの確認と連携状態の表示
  2. 認可したユーザーが配信中の YouTube ライブの検出と動画 ID の取得
  3. ライブチャットの取得・表示（Google OAuth トークンは使用しません）
  4. 連携状態の維持および再接続
  5. ユーザーが明示的に行った操作（連携解除、設定変更、バックアップ等）の実行

Google OAuth を利用して Google API から取得したデータは、上記 1、2、4 のユーザー向け機能の提供以外の目的には使用しません。

3. Google API Services User Data Policy（Limited Use）

本アプリによる Google ユーザーデータの利用および転送は、 Google API Services User Data Policy （Limited Use 要件を含む）に従います。

本アプリは、次の行為を行いません。

  • Google ユーザーデータの、広告プラットフォーム・データブローカー・情報再販業者等への販売または譲渡
  • Google ユーザーデータの、広告配信・再ターゲティング・パーソナライズド広告・インタレストベース広告への利用
  • Google ユーザーデータの、与信判断または貸付目的での利用
  • 広告目的のトラッキング、および本アプリの利用状況を外部解析サービスへ送ること（製品として意図した送信は行いません）
  • YouTube 以外の Google サービスへの不正なアクセス

4. 第三者提供

法令に基づく場合、またはセキュリティ上必要な場合を除き、取得した YouTube 関連データや OAuth トークンを第三者に提供しません。

第 1.4 節に記載のとおり、チャット表示のため OBS 等または同一 LAN 上のリモート操作画面へデータを送る場合があります。これはユーザーの設定および操作に基づくものです。

5. 人による閲覧

運営者およびその関係者は、通常の運用において、ユーザーの Google ユーザーデータ（チャンネル情報・配信情報・OAuth トークン等）を閲覧しません。

次の場合に限り、必要最小限の範囲で取り扱うことがあります。

  • ユーザーがサポート対応のため明示的に同意し、必要な情報を提供した場合
  • セキュリティ上の調査（不正利用や障害の調査等）に必要な場合
  • 法令に基づく場合

6. 保管期間と削除

  • OAuth トークンは、連携中のみ端末に保持します。
  • 本アプリ内で YouTube 連携を解除した場合、保存済みの YouTube OAuth トークンは削除します。
  • ライブチャットの表示用データは、表示や履歴機能のために端末上に保持される場合があります。アプリデータの削除により除去できます。
  • アプリのアンインストール後も、OS やユーザーデータ領域にファイルが残ることがあります。完全に削除する場合は、アプリのデータディレクトリの削除など、OS の手順に従ってください。
  • Google アカウント側でも、Google アカウントのアプリのアクセス権 から本アプリのアクセスを取り消せます。

7. セキュリティ

トークンや秘密情報は暗号化可能な形で端末に保存し、ソースコードや設定のエクスポートに含めないよう設計しています。ただし、端末の不正利用やマルウェア等によるリスクを完全に排除することはできません。

8. 子どもの利用

本アプリは主に配信者向けのツールです。13 歳未満の子どもから、保護者の同意なく個人情報を意図的に収集することはありません。

9. ポリシーの変更

本ポリシーの内容を変更する場合は、本ページの「最終更新日」を更新して掲載します。重要な変更がある場合は、合理的な方法で周知します。
